# AI Music Agent

Personal desktop tool that creates instrumental music with local AI models and publishes it to its owner's YouTube channel.

- Music: ACE-Step 1.5 (acestep.cpp), cover art: FLUX (stable-diffusion.cpp), text: a local Ollama model. Everything runs on the CPU, no cloud AI.
- Pipeline: trend research → track brief → music variants → quality check and mastering → cover, video and Shorts → upload.
- Python 3.11 on Windows; dependencies: numpy, pillow, pyyaml, requests, tzdata.

This repository contains the program code only. Setup, configuration and login data are kept locally.
